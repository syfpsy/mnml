How it works

01

Copy as you normally would

Ctrl+C, right-click, drag and drop. mnml watches in the background and captures text, links, and screenshots without getting in the way.

02

Double-tap Alt to open it

The window opens right next to your cursor. Recent clips are listed immediately, or type a few letters to search through everything.

Alt Alt
03

Click to paste

Click any item and it lands in whatever you were working in. Shift-click to copy it to your clipboard without pasting right away.

The details

The basics, done well.
A few things worth knowing about.

  • Catches everything. Text, links, and screenshots, captured automatically. Links even pull in the page title so you know what you copied at a glance.
  • Search that actually works. Type a few letters and the list narrows in real time. No waiting, just the things that match.
  • Pins for the things you reuse. Keep frequently used snippets at the top. Templates, addresses, whatever you reach for every week.
  • Two sizes. A compact list for quick grabs, and a wider view with tabs to filter by type when you want to browse properly.
  • Updates itself. New versions download quietly while you work. When one is ready, a small notice shows up at the bottom with a restart button.
  • Fully local. No account, no sync, no telemetry. Everything lives in a SQLite file on your machine and goes nowhere.

Release notes

v0.2.2 Apr 28, 2026
  • Auto-update: running copies check for new versions on startup and every 4 hours. Updates download in the background and a small banner appears at the bottom of the window when one is ready.
  • GitHub Actions release workflow: pushing a version tag now triggers a Windows build and publishes the installer to GitHub Releases automatically.
  • Stable download filename (mnml-setup.exe) so the download link on this page always points to the latest build.
v0.2.0 Apr 27, 2026
  • Removed the copy action button from list rows. Clicking a row already pastes, so the button was redundant.
  • Delete now requires a second click to confirm. First click turns the trash icon red; second click deletes. Auto-disarms after 2 seconds or when you click elsewhere.
v0.1.15 Apr 27, 2026
  • Link rows now show the site's favicon, fetched from Google's favicon service with a fallback to the link icon.
  • Subtle per-category tint on each row: blue for text, violet for links, rose for images.
  • The window now opens with its top-left corner at the cursor, instead of offset to the side.
  • Settings panel added to the compact view, not just the expanded one.
  • Fixed auto-paste: the window now properly transfers OS focus before sending Ctrl+V.
v0.1.14 Apr 27, 2026
  • Rewrote show/hide to use opacity and mouse-event masking instead of the OS window cycle. The renderer stays permanently live, which eliminates the flicker on open.

Privacy

mnml stores your clipboard history locally in a SQLite database on your machine. It does not collect, transmit, or share any data. There are no analytics, no crash reports, and no telemetry of any kind. Nothing leaves your computer.
