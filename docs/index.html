How it works

01

Copy normally

Ctrl+C, right-click, drag and drop. mnml captures text, links, and images in the background without changing how you work.

02

Double-tap Alt and type

The window opens by your cursor and focuses the search bar. Recent clips appear immediately, or type to search clips, files, folders, and apps.

Alt Alt
03

Paste or open

Click a clipboard item to paste it into the active app. Click a file, folder, or app result to open it. Shift-click copies without pasting.

04

Keep the index visible

Settings includes a PC search dashboard with drive scope, counts, progress, errors, and a rebuild action when you want a clean index.

The details

Clipboard memory plus PC search.
Built around a local database, not live Windows Search delays.

  • Clipboard history. Text, links, and images are captured automatically. Links include useful metadata so older copies are easier to recognize.
  • Whole-PC Files & Apps search. mnml crawls ready local drives into a SQLite FTS index, then searches that database instead of calling Windows Search live.
  • Newest files first. File and folder results carry modified timestamps and sort by latest modified date at the top.
  • Index dashboard. Settings shows indexed counts, current drive scope, crawl progress, errors, and a rebuild button for a fresh database.
  • Stable summon behavior. Double-Alt summon uses native Windows foreground activation, renderer focus verification, and guard checks to keep search ready.
  • Fully local. No account, no sync, no telemetry. Clipboard history and the PC search index live in SQLite databases on your machine.
